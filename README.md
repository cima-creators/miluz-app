# Páginas de los bots de Mi Luz

Las páginas que usa Luz para elegir y revisar lo que hacen sus bots. Se publican en **cima-creators.github.io/miluz-app/** (GitHub Pages, 1-2 min después de cada push).

| Página | Carpeta |
|---|---|
| Panel con todos los bots | `sistemas/` |
| Estáticos | `estaticos/` |
| Animados | `animados/` |
| Edición de crudos | `edicion/` |
| B-roll + voz en off | `broll/` |
| Ads Random | `random/` |
| Variantes de ganadores (versión de Mi Luz) | `variantes/` |

Reglas: cada página es un HTML de un solo archivo. Los datos están en Firebase (proyecto cleargy-creators), que es de CIMA: si un cambio necesita
una colección o regla nueva de Firestore, avisarle a CIMA. Nada de claves ni datos de clientes en este repo (es público).
